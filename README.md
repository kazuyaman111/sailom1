# ห้องเรียนไร้ขีดจำกัด
### #ห้องเรียนครูชัช

เกมเว็บสำหรับห้องเรียน — นักเรียนตอบคำถามตามหลักสูตร คะแนนที่ได้จะไปฟักไข่ให้กลายเป็นวิญญาณที่เลี้ยงและวิวัฒนาการต่อได้

ไฟล์เดียวจบ ไม่มี dependency ไม่ต้องใช้เซิร์ฟเวอร์ เปิดจากมือถือหรือคอมพิวเตอร์ก็ได้

---

## นำขึ้น GitHub Pages (ใช้เวลาราว 3 นาที)

1. สร้าง repository ใหม่บน GitHub ตั้งชื่อว่าอะไรก็ได้ เช่น `kruchat-classroom` แล้วเลือก **Public**
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (ลากทั้งโฟลเดอร์วางในหน้า *uploading an existing file* ได้เลย)
3. ไปที่ **Settings → Pages**
4. หัวข้อ *Source* เลือก **Deploy from a branch**
5. *Branch* เลือก **main** และโฟลเดอร์ **/ (root)** แล้วกด **Save**
6. รอประมาณ 1-2 นาที เว็บจะขึ้นที่ `https://ชื่อผู้ใช้.github.io/ชื่อ-repository/`

เอาลิงก์นั้นไปแปะใน Google Classroom หรือทำเป็น QR Code ให้นักเรียนสแกนได้เลย

> ไฟล์ `.nojekyll` ที่แถมมาด้วยมีไว้กันไม่ให้ GitHub Pages ประมวลผลไฟล์ด้วย Jekyll อย่าลบทิ้ง

### ถ้าอยากลองก่อนอัปโหลด
ดับเบิลคลิกไฟล์ `index.html` เปิดในเบราว์เซอร์ได้ทันที ทำงานครบทุกอย่าง

## เพิ่มคำถามเอง

**วิธีที่ง่ายที่สุด — ทำใน Google Sheets แล้ววาง**

1. เปิด `question-template.csv` ด้วย Google Sheets
2. กรอกคำถามต่อท้ายตามคอลัมน์เดิม
3. เลือกทั้งตาราง (ไม่ต้องเอาแถวหัวก็ได้) แล้วคัดลอก
4. ในเกม กดแท็บ **ตอบคำถาม → จัดการ → นำเข้าจาก CSV** แล้ววางลงในช่อง กด **นำเข้า**

คำถามที่นำเข้าจะเก็บอยู่ในเบราว์เซอร์ของเครื่องนั้น ถ้าอยากให้นักเรียนทุกคนได้คำถามชุดเดียวกันตั้งแต่เปิดเกม ให้ใส่ลงในโค้ดแทน (ดูหัวข้อถัดไป)

**ลำดับคอลัมน์**

| วิชา | ระดับชั้น | หน่วยการเรียนรู้ | ความยาก | โจทย์ | ก | ข | ค | ง | เฉลย | คำอธิบาย |
|---|---|---|---|---|---|---|---|---|---|---|

- **วิชา** — ใช้ชื่อไทย (`ประวัติศาสตร์`, `การป้องกันการทุจริต`, `คอมพิวเตอร์`) หรือรหัสวิชาก็ได้ เช่น `ส15102`
- **ระดับชั้น** — `ป.1` ถึง `ป.6` หรือ `ม.1` ถึง `ม.3`
- **หน่วยการเรียนรู้** — ดูรายชื่อหน่วยที่ใช้ได้ในหน้านำเข้าของเกม เว้นว่างไว้ระบบจะใส่หน่วยแรกของวิชานั้นให้
- **ความยาก** — `ง่าย` `ปานกลาง` `ยาก` `ท้าทาย` หรือใส่เลข 1-4
- **เฉลย** — ใส่เลข 1-4 หมายถึงข้อ ก ข ค ง

ส่งออกคำถามทั้งหมดกลับเป็นไฟล์ CSV ได้ที่ปุ่ม **ส่งออกเป็น CSV** ในหน้าเดียวกัน

## แก้ไขซอร์สแล้วสร้างไฟล์ใหม่

ต้องมี Node.js ติดตั้งไว้

```bash
cd src
node build.js
```

สคริปต์จะรวมไฟล์ใน `src/js/` ทั้งหมดเข้ากับ `src/template.html` แล้วเขียนทับ `index.html` ที่ราก

**เพิ่มคลังคำถามชุดใหม่**

1. สร้างไฟล์ เช่น `src/js/01c-hist-p4.js` ประกาศตัวแปร `const Q_HIST_P4 = [ ... ]`
2. ลงทะเบียนใน `src/js/01d-bank.js` โดยเพิ่มบรรทัด `{ subj:'hist', grade:'p4', rows: Q_HIST_P4 },`
3. เพิ่มชื่อไฟล์ลงในอาร์เรย์ใน `src/build.js`
4. รัน `node build.js`

รูปแบบแต่ละข้อคือ `['หน่วย', ความยาก, 'โจทย์', ['ก','ข','ค','ง'], เฉลย(0-3), 'คำอธิบาย']`

## ระบบในเกมโดยย่อ

**การให้คะแนน** ตอบถูกได้คะแนนเต็มตามระดับความยากเสมอ (ง่าย 10 · ปานกลาง 20 · ยาก 35 · ท้าทาย 60) ตอบเร็วได้โบนัสเพิ่มสูงสุด 50% ตอบถูกติดกันได้ตัวคูณสูงสุด ×2 ตอบผิดไม่หักสุขภาพสัตว์เลี้ยง แค่สตรีคหลุด และได้ประสบการณ์เล็กน้อยจากการอ่านเฉลย

**ระบบทวนซ้ำ** ข้อที่ตอบผิดจะถูกดันกลับมาถามใหม่เร็วขึ้นตามหลักกล่องไลต์เนอร์ 5 ระดับ ข้อเดิมที่ตอบซ้ำในวันเดียวกันจะได้คะแนนเพียง 25% เพื่อกันการวนตอบข้อง่าย

**ไข่และธาตุ** ไข่โตจากคะแนนฐานของข้อที่ตอบถูก ไข่แต่ละใบจะสุ่ม *ผังธาตุ* ขึ้นมาใหม่ว่าหน่วยการเรียนรู้ไหนให้ธาตุอะไร ดูผังได้จากปุ่มในหน้ากระถาง และตอนฟักมีโอกาส 15% ที่ไข่จะแปรปรวนแล้วสุ่มธาตุเองโดยไม่สนผัง

**สัตว์เลี้ยง** 32 สายพันธุ์ 8 ธาตุ 4 ระดับความหายาก รวม 320 ร่างในสมุดสะสม วิวัฒนาการ 6 ขั้น แตกสายตามวิธีดูแล 3 สาย เลี้ยงพร้อมกันได้ 6 ตัวในสวน

**ขนาดตัวอักษร** กดปุ่ม **Aa** มุมขวาบนเพื่อปรับขนาดตัวอักษรได้ 5 ระดับ ตั้งแต่ 90% ถึง 150% มีตัวอย่างข้อสอบให้ดูสดขณะปรับ ค่าที่เลือกจะถูกจำไว้ในเครื่องนั้น ส่วนแถบหัวและแถบแท็บด้านล่างจะคงขนาดเดิมไว้เสมอเพื่อไม่ให้ล้นจอ

**ไอเทมและของตกแต่ง** มีไอเทม 29 ชนิด แบ่งเป็นอาหาร ยารักษา ผลไม้บำรุงค่าสถานะถาวร เครื่องรางกำหนดสายวิวัฒนาการ ของเร่งฟักไข่ และของเร่งการสำรวจ ส่วนของตกแต่งบ้านมี 20 ชิ้น วางได้ 16 ช่อง แต่ละชิ้นให้โบนัสต่างกัน เช่น ฟื้นสุขภาพเอง เพิ่มความอิ่มจากอาหาร เพิ่มพลังโจมตีในการดวล ลุ้นผลึกเพิ่ม ย่นเวลาสำรวจ และเร่งการฟักไข่ ของบางอย่างซื้อด้วยเหรียญ บางอย่างต้องใช้ผลึกสมาธิที่ได้จากการตอบถูกเท่านั้น

**ดวลปริศนา** นักเรียนกดสร้างรหัสท้าดวลจากวิญญาณของตนแล้วส่งให้เพื่อนทางไลน์หรือเขียนใส่กระดาษ เพื่อนวางรหัสในเครื่องตัวเองแล้วดวลได้ทันทีโดยไม่ต้องต่อเน็ตหากัน การดวลเป็นแบบผลัดกันตอบคำถาม ตอบถูกเท่านั้นวิญญาณจึงจะโจมตีได้ ความแรงมาจากค่าสถานะ ความยากของข้อ และความเร็วในการตอบ รหัสมีรหัสตรวจสอบกำกับ ถ้าถูกแก้ไขระบบจะปฏิเสธ

**หน้าสรุปผล** แสดงความแม่นยำรวม แยกตามวิชาและระดับชั้น และผลสัมฤทธิ์รายหน่วยการเรียนรู้พร้อมลูกศรแนวโน้มที่เทียบผลครึ่งหลังกับครึ่งแรกของ 40 ข้อล่าสุด

## ข้อควรรู้

- **ข้อมูลเซฟอยู่ในเบราว์เซอร์ของเครื่องนั้น** ไม่ได้เก็บบนเซิร์ฟเวอร์ ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะหาย ใช้ปุ่ม **ดาวน์โหลดไฟล์เซฟ** ในหน้าตั้งค่าเพื่อย้ายเครื่อง
- เล่นในโหมดไม่ระบุตัวตน (Incognito) ข้อมูลจะหายเมื่อปิดหน้าต่าง
- ตัวเกมโหลดฟอนต์จาก Google Fonts ถ้าไม่มีอินเทอร์เน็ตจะใช้ฟอนต์ของระบบแทน ยังเล่นได้ปกติ
- คลังคำถามตั้งต้นอ้างอิงตัวชี้วัดหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พุทธศักราช 2551 (ฉบับปรับปรุง พ.ศ. 2560) ควรตรวจทานให้ตรงกับหนังสือเรียนที่ใช้ในห้องก่อนนำไปใช้จริง
